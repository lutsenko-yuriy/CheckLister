# Glossary: Demo mode

Part of the project glossary; the index and the aliases table are in [`docs/GLOSSARY.md`](../GLOSSARY.md).

| Term | Definition | Code symbol |
|---|---|---|
| Demo mode | A session setting, switched with "demo on" / "demo off", in which the links for issue descriptions, issue comments and PRs are clickable and get a QR code on first mention per WU. It stays as set until the user switches it, and the agent warns after a restart, compaction or clear if it is still on. | — |
