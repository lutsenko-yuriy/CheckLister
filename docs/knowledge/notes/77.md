# CheL-77: Dark-appearance app icon variant (iOS 18+) to match the dark splash screen

## Notes

## Debrief summary

### 2026-09-24

**What went well**
- Overall a smooth, well-liked result.
- The plan/implementation/verification work (Single Size icon format migration, reusing the existing transparent-glyph render path, Liquid Glass icon rendering investigation, burst-screenshot verification of the launch-zoom fix) was handled without needing user input.

**What was hard or surprising**
- Being asked to run `brew uninstall cairo` (and later, manual file removal) on the user's machine was surprising — it wasn't obvious why the assistant needed the user to do this rather than handling it directly. The command was handed over without first explaining that it was a machine-level change outside the repo/sandbox, not a permissions formality.

**What to change**
- When a fix requires the user to run a command outside the repo (system packages, machine config, credentials), lead with a one-line reason why it needs *them* specifically before handing over the command — not just drop `! <command>`. Added as guideline 7 in `skills/shared/decision-guidelines.md`.
